Denna laboration handlade om att använda css preprocessorer: olika sätt för att göra koden mer överskådlig och återanvändbar genom att använda sass. Vissa delar var lättare än andra.

Stötte på ett litet hinder med färgschemat, vilket inte berodde på själva koderna. Såg att det var permanent mörkt läge oavsett vilka inställningar jag hade på datorn. 
Fungerade som det skulle i inkognito-fönster, men inte i vanlig flik oavsett vilken webbläsare jag använde.

Visade sig senare att det berodde på att webbläsarna hade mörkt läge på hela tiden. Jag hoppas att det ska fungera som det ska nu: ljust läge ska vara blå/bubbelgum färgad.
